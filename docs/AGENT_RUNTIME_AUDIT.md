## 本机配置

默认本机运行可做全文、已确认知识与关系召回。向量召回需要在后端配置 `AKW_EMBEDDINGS_URL` 和 `AKW_EMBEDDINGS_MODEL`。已保存的向量仅与生成它的模型配置比较。未配置或调用失败时，查询继续走全文和知识证据路径。

在「AI 生成分析」勾选「检索当前项目和共享资料，包括已确认结论的原文」启用工作空间召回。可同时联网或关闭联网，仅使用用户授权的空间资料。已确认结论的入口在「知识维护」，已确认关系的入口在「知识关系」。空间策略和本次外部处理授权仍分别生效。

## 验收重点

- 通过带定位的真实证据校验数值和单位，去除无支持段落。
- 用关联项目、敏感资料、撤回来源以及不同 Embedding 配置验证检索隔离。
- 中断校验阶段后重新获取租约，检查已保存的综合只生成一次。
- 在真实 DeepSeek 和公开来源的合成验收空间验证引用及图片，日常回归使用隔离数据和受控模型响应。

## 建议的补强顺序

1. 建立固定评测集，覆盖无答案问题、来源冲突、撤回、中文专名、日期和单位。先测原文召回与引用支持，再比较重排或增加模型调用的收益。
2. 将现有任务阶段迁入统一调度器，并把工具参数、权限、预算、版本与失败策略集中注册。先落地在文档分析和文献研究这两条路径。
3. 在知识资产召回之外建立可编辑的会话和决策记忆。持续监测模型成本、限流恢复和检索延迟，再选择共享缓存或多跳图检索。
