## 能力边界

当前交付覆盖真实 API 支持的主工作闭环和各专项 Renderer 默认体验。分类图册按真实节点类型分组，未引入推断式语义聚类。并行时间轨、超大图虚拟化、跨页面共享元素转场尚未实现；纵向时间线与完整列表提供当前回退。未把它们显示为可用按钮。

当前契约没有近似/区间日期、逐条 Claim–Evidence 支持类型或表格单元格独立证据，所以不自行推断。自动任务 API 也没有 project_id/附件字段，项目选择和文件处理复用已有研究/来源流程。项目主题封面由用户主动选择，偏好按项目 ID 保存在本机并明确标注；不根据名称随机套图。原有服务端导出器保持现状；新布局不会改变历史版次导出语义。

活动列表受现有接口范围限制，只聚合研究记录和本机最近一次自然语言任务；跨设备全部自然语言任务历史仍需要服务端列表接口。WebView 真机内存/200 节点帧率未测量，不宣称已达性能门槛。Vite 主包约 1.59 MB（gzip 约 495 KB），存在大 chunk 提示，进一步代码拆分属于性能优化项。工作台内多标签浏览、登录站点操作、鸿蒙原生桥接等仍属于架构标注的未来能力。

## 素材

上一轮只生成 HOME-02，素材交付不完整。本轮按两个执行包补齐到 30 张采用原图（新增 29 张，其中首页与九类空状态合计十张独立手机构图），另保留四张拒用初稿。已接入首页双画风、项目主题封面库、研究页、三类专项背景、九类空状态、学习与指南封面，以及离线/中断提示。65 个响应式 WebP 变体总计约 1.93 MB，派生尺寸不计为独立素材。

`packages/client/src/assets/manifest.json` 记录工具、提示词、实际生成日期、原生尺寸、用途、版本、裁切、来源、alt、fallback、审核与拒用信息；原图、优化图、拒用稿分开保存。`EditorialImage` 统一实现 picture/source/srcset、延迟加载、固有尺寸和失败回退。手机首页插画置于输入器之后，其他手机图按状态使用，不挤占主操作。素材全为概念艺术；节点、关系、公式、表格和证据保持真实组件。尺寸限制和逐项对照详见 `ART_ASSET_COVERAGE.md`。字体仍使用本地/系统回退，无额外在线字体请求。
