# Workspace 本地验收

本轮对照交接 UI 设计 §5.3–5.9 和 §6、后端规范 03、06、10，以及《Workspace 可编辑性》。代码位于 `F:\ai-knowledge-workspace`。

## 文档工作台

| 验收面 | 操作 |
|---|---|
| 工作台布局 | 打开任意文档，通过顶部按钮收起导航或检查器。检查器的「画布布局」支持调整两侧宽度。刷新后保留设备布局和文档视图。窄屏使用抽屉。 |
| 正文与精细编辑 | 在正文切换阅读或编辑模式。可新增标题、段落、列表、引用、代码、Markdown、公式、图片、表格及嵌入块，可移动、复制、删除、拖动、拆分和合并段落。通过属性检查器修改标题级别或代码语言。 |
| 行内内容 | 正文可插入行内公式、网页链接、脚注和原文引用。知识链接支持节点搜索、创建、唯一标题匹配和反向链接。公式块可编辑源码并预览 KaTeX 效果。 |
| 共享知识视图 | 思维导图、时间脉络、关系图谱和依赖图从同一批知识节点及已确认关系投影。图谱支持拖动、聚焦、过滤、关系和证据查看。知识页支持维护节点、修改关系并重新审核、撤回关系。时间脉络支持年、年月和精确日期以及粒度切换。 |
| 数据表和科学图表 | 编辑表格单元格或粘贴制表符数据。图表可关联当前文档的表格，支持柱状图、折线图和散点图。表格第一列供横轴使用，接下来最多六列作为数据系列。 |
| 交互清单 | 在正文添加「交互清单」，用它记录实验步骤、论文筛选或交接事项。编辑模式下的勾选会保存到文档版本。 |
| 来源和证据 | 文档可嵌入来源卡片、知识节点或另一篇文档。证据网络展示结论关联的证据与正文引用，可打开对应块、来源和原始摘录。本地 PDF 可以在检查器内定位原页及翻页缩放。图片块支持图注、展示裁切及位置标注。 |
| 选区 AI | 单个行内文本段支持字符级选区。快捷操作进入检查器提交修改提案，用户查看 Diff 后决定是否应用。选区内容也可带入独立研究任务。文档分析继续走后台证据门控。 |
| 导出和归档 | 导出 Markdown、PDF、DOCX、JSON 和 Workspace ZIP，支持历史文档版本。已保存的图表及知识视图可选块导出 SVG 或 PNG。文档导出可选择来源证据和有导出权利的图片。 |

## 三条验收路径

1. **实验记录**。添加数据表，创建一个关联它的科学图表，修改表格单元格并检查图表数据。插入交互清单后勾选校准步骤。导出历史版图表 SVG，检查它使用旧版表格。
2. **论文阅读**。导入 PDF，从第 2 页建立证据，将证据插入文档。切换证据网络，从证据检查器打开 PDF 原页，然后从网络跳回正文引用。对图片添加编号标注。
3. **学习或项目计划**。创建几个知识节点，提交并确认依赖关系，切换依赖图。由正文知识链接进入节点，再从反向链接返回文档。

## 共享接口

- 文档的 `ArtifactDocument` 使用带类型的 Block。图表、表格、图片标注、引用和交互清单在共享 contracts 中验证。图表块可以通过 `table_id` 关联同一文档的数据。
- `GET /v1/artifacts/{id}/projection` 提供作用域内知识、来源、原文证据和嵌入文档摘要。导出支持 `revision_id` 和 `block_id`。历史文档版本固定正文及图表数据，关系类视图查询导出时可见的知识状态。
- Web、Windows 与 Android 复用 `ArtifactRendererProvider`。可用 `createArtifactRendererRegistry` 替换指定块的渲染器。图表在前端和服务端共用同一绘图数据。未知块保留数据并走兼容展示。

## 后续验收项

- 跨段或跨格式运行的 AI 选区、同一 AI 提案按操作挑选接受、独立审阅模式、以及从文档语义自动建议并保存布局。
- 矢量式导图编辑、原生图像裁切、手写批注及协作光标。当前拖动、缩放和坐标布局属于设备交互状态，关系及文档内容由数据模型持久化。
- PDF 与 DOCX 目前以文本呈现公式和知识视图的导出内容。查看器中的公式效果使用 KaTeX，视图可以另存为 SVG 或 PNG。需要验证更多复杂 PDF 的字体和图像兼容性。
- Android 真机及各端中文输入法验证。APK 为调试构建。iOS 和鸿蒙属于后续独立适配。


## Windows 本地打开

本轮生成了 Windows x64 的 NSIS 和 MSI 安装包，以及 Android 调试 APK。验收机器运行了 Windows WebView2 实机自动化，覆盖 SQLite 离线重启、同步、独立文档窗口、KaTeX 字体、图表和 PDF 原页。Web 的 7 个端到端测试与 API 的 21 个测试均通过。

新版独立验收 API 在 `127.0.0.1:4102`，使用 `.data\workspace-preview-db` 和独立对象目录。示例工作空间名为「Workspace 功能验收」，示例文档为「实验研究工作台」。如果旧桌面实例仍在托盘，先从托盘退出，再在 PowerShell 运行：

```powershell
Set-Location 'F:\ai-knowledge-workspace'
$env:AKW_DESKTOP_API_PORT='4102'
npm.cmd run start:windows
```

现有 3000 和 4100 服务仍保留在原端口。自动执行限制拦截了原服务替换和单独启动新版 Web 服务。若需要自行启动已编译的新版 Web，在 PowerShell 运行：

```powershell
Set-Location 'F:\ai-knowledge-workspace'
$env:PORT='3002'
$env:AKW_API_ORIGIN='http://127.0.0.1:4102'
$env:AKW_WEB_DIST='.next-workspace-preview'
npm.cmd run start -w '@akw/web'
```

启动后打开 `http://127.0.0.1:3002`，选择「Workspace 功能验收」。
