# Atelier Atlas · Brand Visual System v3.1

主方向：**A / Archive Editorial（档案编辑）**。用户于2026-11-16选择。B的空间组织用于图谱，C的展签层级用于来源和证据；共享同一套品牌规则，不发展为独立页面主题。

## 版面与信息

首页采用有秩序的非对称构图：研究意图与真实近期成果承担主视觉，小型概念标本位于边缘，工作区数量来自实际数据。最近一项成果获得较大阅读区域，其余采用较轻的档案索引。保留真实任务、资料和创建入口。

文稿以阅读为中心，正文控制在约680–740px，专业知识块使用较宽区域；来源边注仅显示实际正文引用。内容索引按组织探索、验证数据、阅读学习分组，手机收进底部选择面板。切换和排版偏好不创建知识Revision。

图谱保留交互实体、明确方向和逐层探索；思维导图使用分支和层级；依赖图保留DAG/SCC；时间线保留日期精度与Unknown；证据按来源—摘录—主张编排；表格保留研究账簿密度；科学图表保留真实轴、刻度、单位和系列。生成图片不进入数据绘图区替代这些对象。

## 字体

- Editorial Serif：思源宋体/Source Han Serif SC、Noto Serif SC、系统宋体回退，用于中文标题和重要概念。
- Interface Sans：Inter、思源黑体/Noto Sans SC、Microsoft YaHei、系统Sans回退，用于控件和正文UI。
- Technical Mono：IBM Plex Mono、Consolas、系统等宽回退，用于日期、版本、DOI、ID与图例元信息。

本轮不新增远程字体请求；实际使用字体取决于设备安装情况。中文效果以运行截图校准。主标题35–52px，页面标题30–42px，章节23–28px，正文15–16px，UI11–14px。长标题使用平衡换行，手机按阅读顺序重排。

## 素材与材质

素材是独立、可长期复用的对象。常见显示宽度52–220px，采用192/384/768px响应式WebP，保留PNG原图、完整提示词、日期、工具、审核记录和使用位置。纹理只在文稿边缘与小范围分隔中使用；表格和科学数据区保持清晰。

标本、矿物、仪器与地图装饰属于概念插画，不能冒充真实馆藏、实验样品、论文封面或证据。真实来源信息、正文和注释由代码绘制。小型档案印章是实体装饰，不充当审核通过或可信状态图标。原有大图文件保留，页面逐步使用新的局部素材表达。

## 动效与响应式

常规反馈140–220ms，面板约260ms。悬停素材最多轻移2px，仅在支持鼠标且未启用Reduced Motion时出现。没有持续漂浮、粒子或自动播放。

手机首页重排标题、意图与近期成果；图谱采用局部探索/关联索引；文稿阅读优先、内容选择用底部面板；时间线纵向；依赖线性；证据链展开；表格横向或单对象；图表保留可读的轴和图例。Inspector继续使用实际对象的详情与原文回调。

## 适用边界

数据字段不足时保持缺口：不补造时间范围、近似日期、关键路径、任务完成状态、逐点误差或逐单元格证据。品牌系统不改变现有数据契约和审核语义。最终完成度以实际页面截图、功能验证和规划条目清单为准，不以本文件单独宣称全部实施完成。
