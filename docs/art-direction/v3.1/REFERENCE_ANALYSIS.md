# Art Direction v3.1 · Reference Analysis

2026-11-16。参考案例用于研究方法。下文“项目取舍”是本项目的设计推导，不是原作者对本项目的建议。每条均保留原URL；字体仅记录可确认的角色/类别，不擅自识别具体字库。研究截图不进入生产素材目录。

## 四项主导方法

- David Rumsey：地图与分类提供空间和范围组织方法。
- Nature：图解与数据图规格提供科学信息的层级、删减、清晰与可访问性原则。
- Pentagram：统一品牌系统允许内容分区拥有不同表达。
- Weill Cornell：科学故事与图像、数据、目录和长篇排版共同形成阅读节奏。

它们共同约束 Atelier Atlas 的组织方式，不对应四种页面主题。三套Lab方向也不以任何参考品牌命名。

## 逐项研究记录

### A / David Rumsey Maps

- 原案例：[David Rumsey Maps](https://www.davidrumsey.com/)
- 方法：范围→分类→单幅图的逐层导航；将对象置于可探索的空间。
- 构图、字体、色彩、图像/材质：历史地图与索引分层；衬线标题，密集目录，暖棕纸色与地图图像。
- 项目取舍：保留范围/焦点/局部展开的区别；不用古典地图配色、边框或旧网站布局。
- 研究证据：[页面存档](references/david-rumsey.jpg)。

### B / Cartography Collection

- 原案例：[Cartography Collection](https://www.davidrumsey.com/collections/cartography.html)
- 方法：按资料集合和地理主题建立入口。
- 构图、字体、色彩、图像/材质：旧式集合索引；网页文本已读取；本页未单独截图。
- 项目取舍：用于全库/项目范围组织，避免把网页目录样式搬进产品。
- 研究证据：网页/PDF文本记录；本轮无可用独立截图。

### C / Historical Atlases

- 原案例：[Historical Atlases](https://www.davidrumsey.com/view/atlases)
- 方法：年代、地理和主题可以形成互补索引。
- 构图、字体、色彩、图像/材质：分级文字目录和展开入口；截图保留在研究目录。
- 项目取舍：Graph范围与Timeline时期索引分别表达；不沿用复古背景装饰。
- 研究证据：[页面存档](references/david-rumsey.jpg)。

### D / Lehmann Relief

- 原案例：[Lehmann Relief](https://schierenberg.nl/product/66792)
- 方法：线条密度参与空间重量，而不是增加无意义纹理。
- 构图、字体、色彩、图像/材质：原版刻线图/纸张；商品说明已读，大图加载存档受限，不能将加载画面当作清晰原图。
- 项目取舍：仅用于画布边缘的轻量装饰；不覆盖真实节点，不作为地形数据。
- 研究证据：[页面存档](references/lehmann-relief.jpg)。

### E / Pallas Botanical Atlas

- 原案例：[Pallas Botanical Atlas](https://www.librairieclavreuil.com/en/pallas-voyages-en-differentes-provinces-de-lempire-de-russie-et-dans-lasie-septentrionale-traduits-de-lallemand-par-m-gauthier-de-la-peyronie-commis-des-affaires-etrangeres/)
- 方法：一个主体可与局部结构、编号和说明形成信息层次。
- 构图、字体、色彩、图像/材质：书籍/图版/地图的实物与图像展示；衬线书目信息、纸张材质。
- 项目取舍：独立标本素材与真实HTML说明分离；不生成假标签和假文献。
- 研究证据：[页面存档](references/pallas.jpg)。

### F / Wellcome Botanical Illustration

- 原案例：[Wellcome Botanical Illustration](https://content.www.wellcomecollection.org/concepts/mcmtzz9f)
- 方法：图像、作品、相关主题构成不同资料层级。
- 构图、字体、色彩、图像/材质：图像集合、作品记录与关联主题；页面与网页文本已访问。
- 项目取舍：来源类型与元信息分层；生成装饰不能冒充馆藏。
- 研究证据：[页面存档](references/wellcome.jpg)。

### G / Kew Science

- 原案例：[Kew Science](https://powo.science.kew.org/)
- 方法：研究对象需与名称、分布、描述和资料来源同时组织。
- 构图、字体、色彩、图像/材质：网页文本可读，浏览器进入安全验证，未完成标本细节视觉复核。
- 项目取舍：沿用对象与元信息的组合原则；具体图像/字体待可访问时核对，不推测、不绕过验证。
- 研究证据：[页面存档](references/kew.jpg)。

### H / Typographic Grid

- 原案例：[Typographic Grid](https://www.behance.net/gallery/10608343/The-Typographic-Grid-Book-Layout)
- 方法：同一内容可以通过网格、留白与版面比例产生不同阅读顺序。
- 构图、字体、色彩、图像/材质：三套相同文本的书页实验，黑白灰，章节与正文密度差异。
- 项目取舍：Lab共用数据，实质改变构图；不把三套实验做成三套颜色。
- 研究证据：[页面存档](references/typographic-grid.jpg)。

### I / Weill Cornell Magazine

- 原案例：[Weill Cornell Magazine](https://skeltonsprouls.com/new/wcm-fall22)
- 方法：科学故事、概念插画与数据图形形成有节奏的章节。
- 构图、字体、色彩、图像/材质：跨页展示中强标题与目录、图像和边注共存；不同内容区有疏密变化。
- 项目取舍：研究文稿长短段落与来源边注重新组织；不复制医学杂志封面、红紫配色或插画。
- 研究证据：[页面存档](references/weill-cornell.jpg)。

### J / Nivaagaard Identity

- 原案例：[Nivaagaard Identity](https://www.behance.net/gallery/99285513/Visual-Identity-NIVAAGAARD)
- 方法：古典图像和现代字体之间可以形成稳定的识别关系。
- 构图、字体、色彩、图像/材质：浏览器可访问，品牌物料中衬线/无衬线文字、图像裁切和留白形成对照。
- 项目取舍：保留字体角色对比；不复制名称、字体标志、花纹和海报版式。
- 研究证据：[页面存档](references/nivaagaard.jpg)。

### K / Pentagram Exhibition

- 原案例：[Pentagram Exhibition](https://www.pentagram.com/work/new-york-at-its-core/story)
- 方法：统一字体与导览体系下，不同年代/内容允许不同展示策略。
- 构图、字体、色彩、图像/材质：案例说明与展厅图已查看；文字为展区锚点，图像、实物与年代同场。
- 项目取舍：全局字阶/控件一致，Graph/Document/Timeline有不同构图；不做纽约展览主题皮肤。
- 研究证据：[页面存档](references/pentagram.jpg)。

### L / Bratislava City Museum

- 原案例：[Bratislava City Museum](https://www.tabstudio.eu/work/biographies-of-people-and-things)
- 方法：标题作为视觉锚点，小型实体记号形成持续识别。
- 构图、字体、色彩、图像/材质：双语、衬线/无衬线对照、黑白与实物照片，印章贯穿物料。
- 项目取舍：对象展签与短编号采用代码；装饰印章不得充当可信或审核状态。
- 研究证据：[页面存档](references/bratislava.jpg)。

### M / Barcelona Design Museum

- 原案例：[Barcelona Design Museum](https://www.dandad.org/work/d-ad-awards-archive/barcelona-design-museum)
- 方法：简单连接线与文字可组成可扩展的品牌规则。
- 构图、字体、色彩、图像/材质：设计系统以连接线和无衬线排版组织多载体。
- 项目取舍：连接线必须有关系含义；不复制标志轮廓、建筑路径或具体字形。
- 研究证据：[页面存档](references/barcelona.jpg)。

### N / GRASSI Museum

- 原案例：[GRASSI Museum](https://www.ungestalt.de/en/work/grassi-museum-fuer-angewandte-kunst-exhibition-design-for-cultural-affairs)
- 方法：按主题与物件尺度分区，让不同内容共享导览秩序。
- 构图、字体、色彩、图像/材质：大标题、主题色与空间轴线；不同大小物件采用不同陈列结构。
- 项目取舍：来源/证据/主张按对象组织，避免统一等大卡片；不复制展厅色块。
- 研究证据：[页面存档](references/grassi.jpg)。

### O / Henry Moore Institute

- 原案例：[Henry Moore Institute](https://henry-moore.org/henry-moore-institute/whats-on-henry-moore-institute/)
- 方法：时期与事件之间需要节奏和目录，不能只罗列日期。
- 构图、字体、色彩、图像/材质：给定URL现为展览日程，已访问；不能当作指定2024时间线装置已完整核对。
- 项目取舍：真实日期驱动时期索引；原时间线图片加载受限，具体图版细节保留待核对。
- 研究证据：[页面存档](references/henry-moore.jpg)。

### P / Quantum Computing Exhibition

- 原案例：[Quantum Computing Exhibition](https://www.lord.ca/projects/project-experience/institute-of-quantum-computing-iqc-travelling-exhibition)
- 方法：科学概念应通过逐步导览连接，避免无上下文的对象堆叠。
- 构图、字体、色彩、图像/材质：科学展览的空间、图像和阶段导览；案例说明已读并保留页面存档。
- 项目取舍：学习章节/时间事件以问题与阶段衔接；不复制展板、照片和量子题材。
- 研究证据：[页面存档](references/quantum.jpg)。

### Q / Nature Scientific Illustration

- 原案例：[Nature Scientific Illustration](https://www.nature.com/documents/Nature_scientific_illustration_author_guide.pdf)
- 方法：视觉层级、视觉删减、清晰和可访问性共同服务解释。
- 构图、字体、色彩、图像/材质：四页PDF文本已读取；浏览器PDF画面未成功显示，未标记逐页视觉复核完成。
- 项目取舍：信息重要性决定权重；删除冗余装饰，明确箭头和图例含义；不借用Nature品牌色板。
- 研究证据：网页/PDF文本记录；本轮无可用独立截图。

### R / Nature Figure Guide

- 原案例：[Nature Figure Guide](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)
- 方法：坐标、刻度、单位、图例和易读文字优先于装饰。
- 构图、字体、色彩、图像/材质：网页规格及示例已访问，页面存档含初始隐私提示；数据图和文字分离。
- 项目取舍：保留程序化图表；没有误差和置信区间字段时不补造，不放背景素材干扰数据。
- 研究证据：[页面存档](references/nature-figures.jpg)。

### S / Beautiful Reasons / Giorgia Lupi

- 原案例：[Beautiful Reasons / Giorgia Lupi](https://medium.com/accurat-in-sight/beautiful-reasons-c1c6926ab7d7)
- 方法：视觉语言可以来自内容，但必须保持多变量关系可解释。
- 构图、字体、色彩、图像/材质：长文与数据案例已读；整页截图过长失败，保存视口存档。
- 项目取舍：用于组织叙事与交互，不采用原作者具体图表语法或装饰图形。
- 研究证据：[页面存档](references/lupi.jpg)。

### T / Esri Knowledge Graph

- 原案例：[Esri Knowledge Graph](https://www.esri.com/arcgis-blog/products/arcgis-enterprise/data-management/what-is-a-knowledge-graph)
- 方法：实体、关系、方向和空间上下文必须可区分。
- 构图、字体、色彩、图像/材质：官方网页文本已读；浏览器导航超时，无本轮页面截图。
- 项目取舍：同一实体在各视图保持身份，关系方向来自数据；不复制GIS界面或图标。
- 研究证据：网页/PDF文本记录；本轮无可用独立截图。

## 访问与使用边界

所有参考入口均已尝试访问。Kew安全验证、Nature PDF视觉预览、个别大图/超长页面和Esri浏览器导航存在限制，已逐项标注；不把错误页或加载态当作视觉复核通过。Behance的Nivaagaard虽在网页检索通道403，浏览器可正常查看，已保存页面。

现阶段可据已确认的方法继续比较构图；受限原图的细部不作为迁移依据。生产图像仅使用本项目生成素材或明确许可资料，不从研究截图中裁取素材。
