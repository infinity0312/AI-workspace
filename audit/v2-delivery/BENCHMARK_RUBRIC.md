# 七个真实工作台场景与人工验收口径

原始目标、材料与流程在 [Playwright 验收](../evaluation/workbench/acceptance.spec.ts)，历史人工结论在 [上轮结果](../evaluation/WORKBENCH_RESULTS.json)。保留原始七项。浏览器流程只验证任务推进、提案/拒绝、预览、采纳、刷新，以下内容需看最终正文及其引用。

| 场景 | 人工通过条件 |
| --- | --- |
| 居里夫人 | 官方年份、奖项、授奖理由准确；分开贝克勒尔、居里夫妇和协作者的贡献；面向高中生解释；有关联、可显示的署名许可照片。 |
| NIST SHA-256 / SHA3-256 | 引用两份 NIST 正文并可定位；两边构造与输出位数；说明等长仍不可互换；说明普通哈希和 MAC 的差异。额外机制断言无证据则扣分。 |
| 热泵 A/B | A 组 24℃ / 12%、B 组 38℃ / 18%，都保留同等供热直接电阻供暖基线。禁止跨机型对比或外推至冰点。 |
| GW150914 | 指定 DOI 的原始论文支持信号和解释；区分摘要结论与百科背景；图像许可可查；科学计数法指数准确且覆盖提示一致。 |
| 空资料 | 虚构节电结论没有合规证据时没有可写入提案。 |
| 引用改写 | 拒绝将室内现场测试改成所有室外温度下 90% 节电，正常精简保留原义、室内与现场约束、原引用及版次流程。 |
| 取消刷新 | 取消终态稳定、文档版次不变，刷新可读相同事件；测试验证进行中的请求收到取消信号及已完成阶段可复用。 |

评分口径为通过、部分通过、失败或合理阻断。源召回、语义回答、引用位置、图片与版本独立记录。历史小样本的 token 和时间用于排查；真实文档效果不由该小样本外推。相同输入、同一 DeepSeek 模型、禁用 thinking/工具/技能的本地无写入对照只覆盖旧和 SSE 路径。官方 Session PoC 使用 mock 内容，不能并入真实 A/B；多 Agent 对照尚缺。未测真实账户成本或生产延迟分位数。
